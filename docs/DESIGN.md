# Дизайн StarFlow

Источник правды — `design/mockup.jpeg`, двенадцать экранов «личной обсерватории». Экраны повторяют макет по составу, порядку и текстам. Статус-бар устройства не рисуется.

## Цвета

Токены: `frontend/src/shared/styles/tokens.css` и `frontend/src/shared/styles/tokens.ts`.

Отдельной светлой палитры нет. Сегмент «Авто / Светлая / Тёмная» сохраняет выбор в `localStorage` (`starflow-theme`), экран остаётся тёмным.

## Шрифт

Семейство `"Google Sans"` из `static/font`. Размер и насыщенность меняются, файлы и `@font-face` нет.

## Ассеты

`static/` — единственная публичная папка. Иконки: `static/icons/svg`. Иллюстрации: `static/illustrations`. Знак приложения: `static/logo`.

## Экраны

`/welcome`, `/onboarding/birth`, `/`, `/forecast`, `/calendar`, `/natal`, `/compatibility/:personId`, `/chat`, `/people`, `/profile`, `/settings`, `/premium`. Состав каждого экрана записан в `.cursor/rules/design-system.mdc`.
