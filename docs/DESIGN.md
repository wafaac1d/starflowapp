# Дизайн StarFlow

Основной язык — типографический альманах. Ориентир трёх эталонных экранов: главная, календарь, premium. Остальные страницы собираются из той же типографики, сетки, тонких разделителей и редких винных плоскостей.

Файл исходного макета в репозитории не хранится. Композиция ниже записана по описанию варианта 02.

## Что не используется

Плитки, белые карточки, декоративные орбиты, космический фон, фиолетовые градиенты, неон, стекло, золото, тяжёлые тени, частицы, бесконечные анимации и случайные звёзды. Системную шапку Telegram страница не рисует.

## Цвета

Токены лежат в `frontend/src/styles/tokens.css`. Компоненты берут имена токенов, не HEX.

| Токен | Светлая | Тёмная |
| --- | --- | --- |
| `--color-bg` | `#f5f0f0` | `#191416` |
| `--color-surface` | `#f5f0f0` | `#251d20` |
| `--color-text` | `#9b2d30` | `#f5eceb` |
| `--color-text-secondary` | `#b8b8b8` | `#b9aaad` |
| `--color-wine` | `#9b2d30` | `#9b2d30` |
| `--color-on-wine` | `#f5f0f0` | `#f5eceb` |
| `--color-accent` | `#9b2d30` | `#d99a9d` |
| `--color-divider` | вино 18% | `#3b2b30` |

`#b8b8b8` остаётся у несущественной подписи, в том числе у дисклеймера на главной. Цена, ошибка, лимит и подпись поля набираются `--color-text`. WCAG не заявляется.

Выбор темы: `telegram`, `light`, `dark`. На сегменте это подписи «telegram», «светлая», «тёмная». Ключ `localStorage` — `starflow-theme`. Явный выбор светлой или тёмной важнее темы Telegram. Режим `telegram` читает `colorScheme` WebApp, иначе `prefers-color-scheme`. Активный пункт навигации в светлой теме винный, в тёмной — `--color-accent`. На экранах настроек и удаления данных активен пункт «профиль».

## Шрифт и тексты

Семейство — `"Google Sans"` из `static/font`. Веса интерфейса от 400, не тоньше. Авторские строки лежат в `resources/texts/ru` строчными буквами. `text-transform: lowercase` на документ не ставится. Имена, ввод, URL, email и коды регистр не теряют. Emoji в текстах и кнопках нет.

## Ассеты

Источник — каталог `static` в корне. Сборка копирует SVG в `frontend/public`, Vite кладёт их в `frontend/dist`. Образ отдаёт `frontend/dist` тем же процессом, что и API. Путь в клиенте — `/icons/<имя>.svg` и `/illustrations/<имя>.svg`.

| Назначение | Файл |
| --- | --- |
| логотип | `static/logo.png` → `/logo.png` |
| сегодня в навигации | `static/icons/svg/sun.svg` |
| календарь | `static/icons/svg/calendar.svg` |
| близкие | `static/icons/svg/people.svg` |
| профиль | `static/icons/svg/profile.svg` |
| стрелка списка | `static/icons/svg/arrow-right.svg` |
| месяц назад и вперёд | `static/icons/svg/arrow-left.svg`, `arrow-right.svg` |
| луна, карта, история, premium, подарок, закладка, чат, настройки, закрыть, поделиться | одноимённые файлы в `static/icons/svg` |
| иллюстрация premium | `static/illustrations/three-circles-cream.svg` |
| те же круги винным штрихом | `static/illustrations/three-circles-wine.svg` |

Реестр — `frontend/src/components/ui/icons.tsx`: каждый значок импортируется из `static/icons/svg` и показывается как изображение этого файла. Страницы путь не пишут. Декоративная картинка скрыта от чтения с экрана. Кнопка с иконкой имеет текстовое имя.

В `static` нет отдельной иконки «сегодня», дуги винного блока и маркеров круг, квадрат, треугольник. Навигация использует солнце. Дуга и маркеры — геометрия компонента, рядом с маркером всегда есть текст. Файл трёх окружностей — горизонтальный ряд пересечений, не треугольная композиция. Приблизительная замена файла не рисуется. PNG рядом с SVG не используются.

## Экраны

Главная: строка месяца и дня недели, крупное число, короткая фраза, винный блок «главное сегодня», список «прогноз дня», «луна сегодня», «совет дня», дисклеймер, нижняя навигация. Дата считается в часовом поясе устройства. Текст блока берётся из уже готового дневного чтения, иначе из ресурса.

Календарь: месяц, подпись ритма, горизонтальная лента дней выбранного месяца, заголовок выбранного дня, шкала «отношения», «работа», «для себя», кнопка «весь месяц». «весь месяц» открывает сетку месяца. Смена дня сразу меняет заголовок и тексты шкалы. Запрос предыдущего дня на экране не остаётся.

Premium: винная плоскость, подпись, заголовок, иллюстрация из `static`, список преимуществ, цена и срок из ответа биллинга, pill-кнопка покупки, строка автопродления. Активная подписка показывает управление продлением. Статус счёта не выдаёт premium.

Профиль, полный прогноз, астропомощник, близкие, натальная карта и настройки следуют тому же альманаху: заголовок около 30 px, списки с тонким разделителем, pill-кнопки, без карточек на каждую строку. Общие части — `PageHeader`, `EditorialListRow`, `PeriodTabs`, `ThemeSelector`, `Switch`, `ProfileSummary`, `CompatibilityEntry`, `ChatMessage`, `ChatComposer`, `NatalChartView`, `BottomNavigation`.

Профиль: имя как в записи, знак и строка premium только если период активен, затем нумерованные переходы. Дата и время рождения — подпись строки «данные рождения»; неизвестное время не показывается как 00:00. Правка этих полей открывается отдельным шагом. Удаление данных — в «данные аккаунта», с подтверждением.

Полный прогноз дня, недели и месяца: дата устройства, заголовок ответа, переключатель периода. Месяц с дневного и недельного чтения открывает `personal_month`, и paywall остаётся серверным. Текст — ответ API, без выдуманных разделов. Закладка и ссылка не создают вторую запись, пока первая не завершилась. Поздний ответ другого периода на экран не попадает.

Астропомощник: вопрос справа в винном блоке, ответ слева на фоне страницы. Поле — «ваш вопрос», отправка — круглая кнопка с `arrow-right.svg`: отдельной иконки отправки в `static` нет. Enter в поле переносит строку и не отправляет. Черновик остаётся, если ответ не сохранён. Остаток вопросов берётся из поля `remaining` ответа на вопрос. Список сообщений этого числа не содержит, и клиент его не вычитает.

Близкие: имя как введено, дата рождения если она есть, без выдуманного знака. Кнопка «добавить человека» открывает форму с согласием. Винный блок ведёт на совместимость. Удаление и разрешение хранения остаются на строке.

Натальная карта: дата, время и место из профиля. Знак `static/icons/svg/natal-chart.svg` — иллюстрация раздела, не рассчитанное положение планет. Дома и асцендент пишутся как неизвестные, если исходных данных нет. Разделы берутся из `sections` ответа.

Настройки: сегмент темы, переключатели прогноза дня, лунного календаря и ретро, время и пояс с сохранением регистра пояса. Ошибка сохранения не подменяет черновик ответом сервера.

В `static` нет отдельного файла натального круга с домами и планетами. Приблизительный круг с точками не рисуется.

## Проверка

Смотреть ширины 320, 390 и 430. Обе темы переключаются в настройках. Длинный текст переносится, горизонтального скролла страницы нет. `prefers-reduced-motion` выключает анимацию загрузки и смену стартовой фразы.
